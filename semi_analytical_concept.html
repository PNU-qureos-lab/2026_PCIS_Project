Estimating depth and bottom composition

The complete semi-analytical calculation flow

C4 is the mean relative squared spectral error over the four input bands. Select a stage above or use the arrow keys.

STEP 01 / 06

Prepare inputs and link deep-water conditions

Prepare the water optical properties in stages 1–2, then apply stages 3–6 to each shallow-water case.

INPUT HydroLight Rrs · bottom spectra · pure-water coefficients →OUTPUT shallow-water cases · matched deep-water conditions

Four spectral bands

Read HydroLight remote-sensing reflectance at 443, 490, 560, and 665 nm. Match shallow and deep-water cases with the same chlorophyll (CHL), suspended matter (TSM), and solar zenith (SZ) settings.

Reference depth, composition, and IOP values are retained separately for evaluating the final model solution.

Input roles

Pure-water constants and notation

Use H2OabDefaults_SEAwater.txt for aw and bw, with bbw = 0.49997 bw. Interpolate the 443 nm constants from 440 and 445 nm. Rrs is above-surface remote-sensing reflectance; rrs is below-surface reflectance.

Implementation: step01_rrs_data.py

STEP 02 / 06 · DEEP-WATER OPTICS

Initialize and optimize PGX

Fit P, G, and X to deep-water HydroLight reflectance, then derive absorption a and backscattering bb.

INPUT deep-water Rrs · aw · bbw · SZ →OUTPUT PGX · a · bb · attenuation by condition
01

Generate 27 starting combinations

Multiply each empirical initial parameter independently by 0.5, 1.0, or 1.5. Interpolate or extrapolate the wavelengths needed by the initial-value equations from the four observed bands.

02

Reconstruct deep-water reflectance

Use PGX to estimate a and bb, calculate u, and reconstruct below-surface deep-water rrs. Convert it to above-surface Rrs and compare it with the HydroLight input.

03

Optimize and choose the lowest error

Update parameters by steepest descent with a Brent line search. Keep the converged candidate with the smallest deep-water IOP objective.

The selected IOPs and solar angle determine XC and XB. These attenuation terms stay fixed during the later H–F search.

Implementation: step02_hope_pgx.py

STEP 03 / 06

Build nine initial H–F candidates

Choose a bottom pair and initial fraction F0, then find an independent starting depth H0 for every candidate.

INPUT shallow-water Rrs · estimated IOPs · attenuation · bottom spectra →OUTPUT nine candidates with pair, H0, F0, and C4

Three bottom pairs × three fractions

Pairs: sand + brown algae, sand + green algae, and brown algae + green algae. For each pair, set the initial fraction of its first component to 0.75, 0.50, or 0.25.

ρb,mix(λ) = F ρb,first(λ) + (1 − F) ρb,second(λ)

Find H0 independently

Hold F0 fixed, reconstruct four-band Rrs, and use Brent search over H ≥ 0 to minimize C4. The same depth is used for all four bands of that candidate.

C4 = meanλ ∈ {443,490,560,665} [(Rrs,model − Rrs,input) / Rrs,input]2

Depth search settings

Include H = 0 in the comparison. Starting points 0 and 1 m do not impose an upper bound; relative tolerance is 10−4, with up to 500 internal iterations.

Implementation: step03_initial_seeds.py

Decision rule

  1. Reconstruct Rrs and calculate C4 at all eight valid neighbors.
  2. Move to the lowest neighbor only if its C4 is strictly smaller than the current value.
  3. Repeat from the new position; stop when no neighbor improves C4.

Depth remains H ≥ 0. H moves by 0.1 m; F moves by 0.01. The F search has no separate interval constraint in this calculation.

Computation limit

At most 10,000 C4 evaluations per candidate, including the initial depth calculation. If the limit is reached, retain the best value evaluated so far and record the stop status.

Implementation: step05_optimize_seeds.py

STEP 06 / 06

Choose the final solution

Compare the five optimized candidates by final C4. Report the bottom pair, depth H, and component fractions from the lowest-error candidate.

INPUT five final H–F candidates and C4 scores →OUTPUT selected bottom pair · H · component fractions

Selection

  1. Sort by final four-band spectral error C4.
  2. Select the candidate with the minimum score.
  3. Convert pair fraction F into fractions for sand, brown algae, and green algae.
  4. Record estimates and candidate diagnostics for review.

Interpretation

C4 measures the fit between input and reconstructed satellite-band reflectance. It is a spectral-fit objective; accuracy against reference values must be assessed separately.
