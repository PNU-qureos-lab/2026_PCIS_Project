Satellite Bathymetry Workflow

Sentinel-2 and Planet Dove glint correction, corrected remote-sensing reflectance, semi-analytical processing, and mapped results.

Project website

Open a section below. The public repository contains documentation, lightweight preview figures, result maps, and the processing code. Large source satellite files are distributed separately.

Data InventoryScene counts, locations, dates, sensor specifications, and package coverage. Sentinel-2 Glint CorrectionACOLITE Cycle 0, residual-glint review, conditional Cycle 1, Rrs, and quality control. Planet Dove Glint CorrectionHedley training-water selection, regression fitting, correction, Rrs, and quality control. Semi-analytical ProcessingDeep-water Rrs selection, optical initialization, depth, bottom fractions, and model checks. Result ViewerSentinel-2 and Planet Dove depth, sand, seagrass, benthic, and status maps. Processing CodeSmall code-only distribution for the complete workflow; raw satellite data are not stored in GitHub.

Data notice: The public repository does not include the large Sentinel-2 source scenes or licensed Planet Dove source imagery. Use the separate delivery package for complete example inputs and reproducible runs.
