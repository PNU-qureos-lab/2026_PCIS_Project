Semi-Analytical Processing (Version 42)

Portable English guide for the Sentinel-2 20 m and Planet Dove native 3 m semi-analytical application.

Start here

Run RUN_GUI.bat in the package root and select option 3. The launcher detects the package location automatically and creates the offline Python environment when required.

Required inputs

  • Glint-corrected Rrs bands for the selected sensor.
  • A valid-water or analysis mask on the same grid.
  • GEBCO depth data for deep-water reference selection.
  • Two or three bottom-reflectance spectra from the packaged library.
  • Solar zenith angle and the required sensor/water-case settings.

Guided workflow

1. Analysis settings: select Sentinel-2 or Planet Dove, the water case, output folder, and processing settings.

2. Image and deep water: select the corrected Rrs data and mask, then review or create the deep-water reference.

3. Bottom selection: choose two or three packaged bottom spectra.

4. Run and results: validate all inputs, start the calculation, follow progress, and open the saved result folder.

Saved products

The workflow saves georeferenced depth, bottom fractions, the selected bottom combination, status and quality layers, tabular pixel results, provenance, preview maps, and an HTML result summary. Scientific raster values are stored in GeoTIFF files.
