# Pacific Island Project — private satellite package

This folder is prepared for a **new private repository with fresh Git history**. It includes only Sentinel-2 and Planet Dove inventory information, semi-analytical source code, glint-correction source code, and offline HTML pages. Do not merge or push the existing public repository history into it.

## Open the HTML

Download the repository ZIP from GitHub, extract it, and double-click `index.html`. Its links to the inventory, method, and glint pages work in a normal browser without GitHub Pages or a local server. For collaborators, share the **private repository link**; they must be invited to the repository and download the folder to use the pages.

## Scope

No field-survey datasets, coordinates, measurements, imagery, or validation outputs are included. The copied Python code may expect input datasets when run; those inputs are intentionally not bundled.

GitHub's HTML file preview displays source rather than an interactive page. Do not enable GitHub Pages for this repository unless the site is explicitly approved for public viewing or private Pages access is configured by an eligible Enterprise account.
