# Pacific Island Project — private satellite package

This package has fresh Git history and contains interactive satellite-only HTML pages, semi-analytical Python code, and glint-correction Python code. It excludes Tidung field-survey files, UAV and underwater imagery, and field-depth validation files.

## Open the pages

Download the entire repository ZIP, extract it, and open `index.html` in a browser. Use the links to browse the satellite inventory, Sentinel-2 model products, and interactive glint-correction results. The pages use relative local assets and do not depend on GitHub Pages. Do not open only an individual HTML file without its asset folders.

Invited collaborators can download the private repository. GitHub's file preview displays HTML source; it does not host a private interactive website. Leave GitHub Pages disabled because its site is normally public.

The inventory and model result previews are satellite-derived, and the glint figures are satellite processing diagnostics. None of these pages provides survey validation. Python scripts require separately authorized inputs to run.
