# Semi-analytical inversion

The semi-analytical workflow estimates shallow-water depth and benthic composition from glint-corrected satellite reflectance. Choose a sensor package:

- [Sentinel-2](sentinel_2/) — four-band HOPE/D2 inversion with bundled reference spectra, one runnable example scene, and step-by-step outputs.
- [Planet Dove](planet_dove/) — four-band Planet Dove experiment with prepared inputs, code, output GeoTIFFs, and quality summaries.

Open the [combined interactive results viewer](../semi_analytical_map.html) to select a sensor, scene, and product, click a grid cell for its numeric value, or save a map with its legend.
