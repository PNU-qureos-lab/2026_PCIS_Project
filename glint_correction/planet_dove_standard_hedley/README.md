# Tidung Planet SuperDove standard Hedley package

Open `Tidung_Planet_Dove_Standard_Hedley_Results.html`. This folder is separate
from the Sentinel-2 workflow and contains complete generated results for four
PlanetScope scenes, intermediate products, runnable code, approximate Rrs/rrs,
and scene/band QC.

Raw Planet imagery is intentionally not redistributed. See `01_INPUT/README.md`
for the required filenames and `02_RUN_WORKFLOW/README.md` for the command.

Start with `00_READ_ME_FIRST/FINAL_ANALYSIS.md`: the workflow calculated every
scene, but calculation does not imply scientific acceptance. The strongest
current candidate is 2025-11-17 and remains conditional on independent
validation; 2026-06-27 is explicitly rejected by QC.
