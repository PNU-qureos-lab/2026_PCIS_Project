  • Code and GUI modes
  • Portable Python and offline wheels included

Included Study Areas

Resolution is explicit: Sentinel-2 processing is 20 m. Planet Dove glint correction and prepared v42 input are native 3 m. The complete pre-existing Tongatapu, Funafuti and Savave semi-analytical examples are clearly labelled 21 m.

Input requirements

Data Specifications

Expected sensor products, spatial resolutions, masks, reference data and principal outputs.

Sentinel-2 MSI

Input
Level-2A bottom-of-atmosphere reflectance
Processing grid
20 m
Glint support
SWIR selection, transferred glint factors, HydroLight evidence
Primary output
Corrected BOA, above-surface Rrs, below-surface rrs and QC

Planet Dove / SuperDove

Input
Eight-band analytic surface reflectance + UDM2
Glint resolution
Native 3 m
Method
Standard Hedley using 866 nm and reviewed offshore training water
Primary output
Corrected SR, approximate Rrs, masks, slopes/R² and QC

Reference data

Bathymetry
Official GEBCO 2026 site subsets
Optical library
HydroLight reference spectra
Deep water
GEBCO ≥30 m, ≥1.5 km from land, 7×7 ROIs, visible CV ≤5%
Masking
Land, cloud, invalid water and shallow/deep selection masks

Semi-analytical v42

Input
Corrected Rrs + masks + deep-water Rrs + sensor configuration
Outputs
Depth, sand/seagrass or multi-bottom fractions, status/habitat and relative RMS
Maps
GeoTIFF scientific rasters plus titled PNG figures with legends
